Overview

This repository focuses on a comprehensive range of data imputation techniques used to handle missing values in datasets. It covers methods from simple statistical approaches to advanced machine learning, state-space models, and deep learning frameworks.

Motivation

Missing data is a common challenge in real-world datasets, particularly in financial and economic applications. The choice of imputation method can significantly impact model performance and inference. This repository aims to systematically explore and compare different techniques to better understand their strengths, limitations, and use cases.

Methods Covered
🔹 Statistical Techniques: Mean, Median, and Mode Imputation, Forward Fill and Backward Fill
🔹 Regression-Based Methods: Linear Regression, Ridge Regression, Lasso Regression
🔹 Machine Learning Approaches: K-Nearest Neighbors (KNN) and Random Forest
🔹 State Space Models: Kalman Filters for time-series imputation
🔹 Deep Learning Methods:Neural network-based imputation techniques

Objective

The goal of this repository is to provide a structured framework for understanding and implementing various imputation techniques, ranging from simple to advanced, and to evaluate their effectiveness across different types of data and missingness patterns.

Applications
Financial time series data
Macroeconomic datasets
General machine learning pipelines
